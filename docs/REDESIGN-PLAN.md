# План переноса редизайна

Макеты: https://claude.ai/artifact/XCEFYpVNyw5MXeJAjcy8Tt (холст Design, мобильная
ширина 390 px).

Отметки: `[ ]` - не начато, `[~]` - в работе, `[x]` - сделано и подтверждено
владельцем.

## Принятые решения

- Главное число на Обзоре - расход за месяц из лимита и остаток. Суммы «на день»
  нет.
- Плашка «укладываетесь ли» появляется за 10 дней до конца месяца.
- «Обычный месяц» - медиана по 6 последним полным месяцам. «Обычно к этому дню» -
  медиана накопленного расхода к сегодняшнему числу. Прогноз на конец месяца -
  уже потрачено плюс медиана остатков (сколько каждый из 6 месяцев потратил после
  этого числа). Дни 29-31 в коротких месяцах приравниваются к последнему дню.
  Меньше 3 полных месяцев - прогноз не показываем.
- Выбранный на Обзоре счёт фильтрует только сводку Обзора. У Истории свои
  фильтры.
- Листания месяцев свайпом нет: месяц выбирается кнопкой в заголовке.
- Нажатие на «Доход» в сводке открывает Историю с фильтром «Доходы».
- Год и «всё время» остаются в выборе периода на Обзоре, без полосы лимита.
- `PlannedPaymentsView` удаляется.
- Банковский модуль остаётся в коде без входа в интерфейсе.
- Внутренние экраны и листы открываются через `location.hash`, чтобы системный
  жест «назад» их закрывал.

## Этапы

### [x] 0. Основа

Новые токены в `src/index.css` (шрифт Onest, палитра макетов, радиусы) при
прежних ролевых именах. Примитивы в `src/components/ui/`: строка списка,
заголовок экрана с кнопкой «назад», пустое состояние, встроенное предупреждение,
тост. Удаление `PlannedPaymentsView`.

### [x] 1. Каркас навигации

Нижняя панель на пять мест (Обзор, История, «+», Аналитика, Ещё); `summaryView`
заменяется на `screen`, внутренние экраны - через `location.hash`. Разметка из
`App.jsx` выносится в `OverviewScreen`, `HistoryScreen`, `AnalyticsScreen`,
`MoreScreen`; загрузка данных пока остаётся в `App`. История - экран вместо
шторки, на `TransactionList` и `usePagedHistory`.

### [x] 2. Серверный расчёт «обычного месяца»

Чистый модуль `server/typicalMonth.js` по правилам выше, с теми же фильтрами
счёта и категории и теми же исключениями (переводы, «не в статистике»), что у
остальных итогов. Поле `typicalMonth` в ответе `/api/stats/dashboard` для
`timeRange=month`. Юнит-тесты модуля и тест роута.

### [x] 3. Обзор

Карточка «расход из лимита», выбор месяца в заголовке, плашка последних 10 дней,
компактная лента счетов, последние операции, «+» вместо трёх кнопок.

### [x] 4. Форма операции и список операций

Переключатель типа внутри формы, крупная сумма, остаток лимита после траты,
ошибка сохранения блоком над кнопкой без потери введённого.

Список операций (История, «Последние операции» на Обзоре, результаты поиска)
по макету «История»: дата и сумма дня над белой карточкой дня, строки с
иконкой, названием и подписью «категория · счёт · комментарий», суммы в
формате «−€24,90» / «+€3.900,00», части разделённой операции вложенными
строками.

### [~] 5. Аналитика

График темпа (факт, «обычно», прогноз, лимит), полосы категорий с изменением к
той же дате прошлого месяца вместо `CategoryDonut`, `MonthlyTrend` с линией
лимита, итоги периода. `getPaceForecast` больше не используется.

### [ ] 6. «Ещё» и настройки

Разбор `AccountsSettingsModal` на экраны: счета (dnd-kit), лист счёта, категории
(меню, переименование в строке), лист лимита с графиком за 6 месяцев, корзина с
подтверждением в карточке, синхронизация, выгрузка CSV, выход.

### [ ] 7. Пустые состояния и ошибки

Экраны по макетам; строка «данные устарели» вместо красной карточки; тосты;
замена всех `window.confirm()`.

### [ ] 8. Уборка

Удаление неиспользуемого параметра `active` у `useBodyScrollLock`,
`CategoryDonut`, `getPaceForecast` (`useSnapCarousel`, `SummaryCard` и
`AccountCards.css` ушли на этапе 3, цвета счетов теперь в `accountThemes.css`);
обновление README и e2e-фикстур (в том числе моков `/api/planned-payments`).
