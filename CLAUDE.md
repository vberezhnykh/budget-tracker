# Правила работы

## Выбор модели

- **Планирование, архитектура, разбор сложных багов — Opus.** Любой этап, где нужно
  принять решение о структуре кода или выбрать подход, делается на Opus.
- **Написание кода по готовому плану — Sonnet.** Когда план утверждён и задача
  сводится к реализации, переключаться на Sonnet.

Практически: планируем на Opus (`/plan`, агент `Plan`), реализацию делегируем на
Sonnet (`Agent` с `model: sonnet` или `/model sonnet`).

## Git и порядок работы

- Пул-реквесты не используем. Готовый этап коммитим и пушим прямо в `main`.
- Перед пушем прогоняем то же, что CI: `npm run lint`, `npm test`,
  `npm run test:e2e`, `npm run build`. Пушим только при зелёном результате.
- После пуша сообщаем, что сделано, что владельцу нужно сделать (например,
  перезапустить сервер или задать переменную) и что проверить руками.
- Следующий этап начинаем только после того, как владелец подтвердит, что всё в
  порядке.
